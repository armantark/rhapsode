Linear Mastery Runway

Random card order is correct for vocabulary decks because each card is independent. Recitation is the opposite: each line is the cue for the next line. This plan makes the whole practice loop follow the passage order, and it locks each new line behind mastery of the lines before it.

1Evidence: a pure one-line gate is too slow

A throwaway simulation modeled the real ladder (about 15 successful recalls for each line), the 12-card session cap, juncture learning, and expanding review intervals. The table shows days to master a 10-line passage at 85% recall accuracy, one session per day. The purist gate ("finish line N fully, then start line N+1") fails: the ladder deals one card per line per session, so the learner waits months. A sliding window of 3 lines keeps strict order and costs only 4 extra days.

2The runway model

Lines unlock only in passage order. A line enters the active window when it is one of the first W lines that are not yet mastered. "Mastered" means the guided ladder is complete (learning_step = None and acquisition succeeded) — no new database fields, no migration. Everything behind the window stays in review. Everything ahead of the window stays locked and is never dealt.

Each session is one pass through the passage: due reviews of the mastered prefix in passage order, then each window line as a block of up to 3 ladder reps, then ready junctures, then one forward chain across the learned prefix as the finisher. Ladder prompts rebuild at deal time, so the second and third rep of a block show the advanced cue level.

4What is removed, what stays

Removed from automatic planning

  • random_start leaves every smart cycle and the fill rotation.
  • _shuffle_random_start_turns is deleted.
  • Triage rank no longer selects which lines to deal; the runway does. Dueness still orders the review portion.
  • NEW_UNITS_PER_SESSION trickle is replaced by the window gate.

Kept

  • FSRS decides when a mastered line returns; the passage decides in what order.
  • The guided ladder itself (it is already linear inside a line).
  • Mode variety on mastered lines (typed, meaning, chaining) — variety of retrieval, not of order.
  • random_start and recital stay as manual modes you launch on purpose.
  • Undo, latency budget ("minutes"), collections (the runway spans member passages in collection order).

7Risks

  • Blocked reps compress the ladder's spacing inside a session. The simulation did not model a massed-practice penalty. If mastery feels hollow, reduce reps per block to 2 before touching the gate.
  • The live Iliad data has lines mid-ladder out of order (triage introduced them). On first run the mastered prefix may sit behind a started-but-unmastered line; the window simply contains that line — no data repair needed.
  • W=1 remains available but the pacing cost is real (section 1). The setting copy must state it.
